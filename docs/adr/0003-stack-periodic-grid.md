# Chemistry-grid stack with per-tile glow, unnamed families

The Stack section needs a Breaking-Bad-style periodic table that still reads as this site. We chose a true 18-column chemistry grid with gaps plus a detached f-row for learning/future elements, tech families grouped by spatial proximity with no names or labels, and one MagicBento card per element with every effect off except spotlight and border glow in brass (cold in dark-world).

Considered Options: named/labeled blocks like spdf (rejected: more than four families and still growing, labels would rot); serial numbers on tiles (rejected: versions carry more signal, kept top-right); custom-built glow (rejected: MagicBento is the mandated component, calmed down for small tiles).
Consequences: the old green tile fill goes away; About decouples from tile data with a static chase line; the pinned-stage scrub stagger retargets at the new cells; reduced-motion and coarse pointers get static tiles with no glow.
