# Portfolio

Personal developer portfolio: a single-route, full-screen-section site that reads as minimal TUI brutalism and hides fan-only traces in plain sight.

## Language

### Site shape

**Section**:
One full-screen band of the single route (Hero, Philosophy, About, Experience, Stack, Projects, Contact, in narrative order).
_Avoid_: page, route, screen

**Coming-soon shelf**:
The Projects section in its pre-project state: an empty listing plus engineered spec slots (numbered S.01–S.03 with spec rows), never fake projects.
_Avoid_: placeholder projects, dummy cards

### Fan vocabulary

**Fan trace**:
A passive covert reference (a sigil, a number, one line of copy) that only a fan of the source recognizes; never explained in the UI.
_Avoid_: easter egg, shout-out

**Easter egg**:
A hidden interaction reached only through a deliberate action (a typed command, a key sequence), such as the dark-world flip.
_Avoid_: fan trace, gimmick

**Triquetra**:
The three-lobed sigil borrowed from Dark; the site's only recurring mark (favicon, loader, divider).
_Avoid_: logo, icon

**Dark-world theme**:
The alternate theme reached by typing `sic mundus` in the hero prompt; the site's "second world", not a generic dark mode.
_Avoid_: dark mode, alternate theme

**Periodic tile**:
A skill rendered as a Breaking Bad-style periodic-table element (symbol + index), the only Breaking Bad visual allowed.
_Avoid_: skill badge, pill, chip

**Sweeping seconds**:
The scroll progress rendered as a mechanical watch's sweeping seconds hand with tick easing.
_Avoid_: progress bar, scroll indicator

**Hidden 18**:
The covert Virat Kohli trace: the number 18 surfaced as a version or tally mark (e.g. `v1.8`, `18*`), never as imagery.
_Avoid_: tribute, jersey reference
